Política de privacidad

Segundo Cerebro es una aplicación de uso personal creada y utilizada únicamente por Daniel González Sánchez (el "titular"). No está disponible para el público ni para terceros.

Qué datos usa

La aplicación accede, con autorización expresa del titular mediante OAuth de Google, a las tareas de Google Tasks de la cuenta del propio titular: títulos, notas, fechas y estado de cada tarea. No accede a datos de otras personas.

Para qué

Para crear, leer y marcar como completadas las tareas del titular, de modo que aparezcan en su calendario y en su reloj. No hay otra finalidad.

Dónde se guardan

Los datos se procesan en el equipo personal del titular. El token de acceso se guarda cifrado por el sistema operativo en ese equipo y nunca se publica ni se comparte. No se almacenan copias en servidores de terceros ni se usan para publicidad, análisis o entrenamiento de modelos.

Con quién se comparten

Con nadie. La aplicación no transfiere datos a terceros.

Uso de la información de Google

El uso de la información recibida de las API de Google se apega a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocación y eliminación

El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, la aplicación deja de tener acceso; los datos locales se eliminan borrando el token almacenado en el equipo.
